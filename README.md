## English

**NEON MYTHOS** is a browser-based living future city where AI agents move, work, negotiate, learn, and pursue long-term goals on their own.

### What you can do
- 📱 **Play instantly on mobile** — responsive UI, fullscreen-friendly layout, PWA support, and “Add to Home Screen”.
- 🎯 **Get a daily mission** on first launch and jump into the city with one tap.
- 💬 **Give long-term work in natural language** — e.g. “Spend a week making this district more lively.”
- 🤖 **Create your own buddy agent in 3 taps** — face, personality, specialty — then let it walk the city and do your work.
- 👜 **Errand-style AI interaction** — the agent receives your request, replies, thinks, says it is leaving, then physically runs toward a relevant building.
- ✨ **Visible route FX** — `! → 💭 → 🏃` appears above the agent and a temporary neon route points toward the destination.
- 🧠 **Autonomous long-term tasks** — milestones, learning, replanning, alliances, rival behavior, reports, mastery, and persistence across browser sessions.
- 🌙 **Real-time atmosphere** — the city lighting reacts to the actual time of day.
- 🪙 **Safe demo wallet** — experiment with a virtual ¥100 balance without moving real assets, with a route toward the x402 / Solana build.
- 🎬 **Cut-ins and a 30-second highlight reel** for milestones and major outcomes.

### Long-term goals
| Goal | Typical horizon |
| --- | --- |
| 💰 Grow earnings | 7 days |
| 📡 Build data supremacy | 6 days |
| 🏙 Grow district control | 8 days |
| 🤝 Build a contract network | 6 days |
| 🏗 Complete a construction project | 6 days |
| 📈 Run a long arbitrage cycle | 7 days |

Long-term tasks persist locally. The deployed build also includes **minimal offline catch-up**: when a task has demonstrated measurable progress online, elapsed offline time can extrapolate that observed rate. Tasks with no observed progress receive no free progress.

### 主な体験
- 📱 **スマホですぐ開始** — レスポンシブ、全画面向けUI、PWA、「ホーム画面に追加」に対応。

- 🤖 **3タップで自分の相棒AIを作成** — 顔・性格・得意分野を選ぶと、実際に街へ登場して仕事をします。
- 👜 **AIに“お使い”を頼む感覚** — 依頼を受ける → 返事 → 考える → 「行ってくる」→ 実際に目的施設へ走ります。

- 🧠 **自律Long-term Task** — マイルストーン、学習、再計画、同盟、競争、日次報告、熟練度、セッションをまたぐ保存。
- 🌙 **実時間リンク** — 現在時刻に合わせて街の光やネオンの雰囲気が変化します。

- 🎬 **成果カットイン＋30秒ハイライト** — 大きな成果を短い演出で確認できます。

**収益成長 / データ覇権 / 地区支配 / 契約ネットワーク / 建設プロジェクト / 長期アービトラージ**

タスクはブラウザに保存され、再読み込みしても継続します。さらに最小構成の**オフライン進捗**を実装しており、オンライン中に実際に観測された進捗速度がある場合だけ、その実績を基準に離席時間を反映します。進捗実績がないタスクには無料の進捗は付きません。

## Deployment / 開発メモ

GitHub Pages deployment is automated by [`.github/workflows/pages.yml`](.github/workflows/pages.yml).

- Every push to `main` triggers the Pages workflow.
- The workflow syntax-checks the Python patchers and JavaScript experience layers before deployment.
- The repository is staged into `_site/`, then the offline-task, errand-mode and route-FX patches are injected into the generated `index.html`.
- The staged build is checked for the required event bridges (`nm:ltt-command`, `nm:route-agent`, `nm:agent-routed`, etc.) before upload.
- `.nojekyll` is used so repository assets are served verbatim.

### Relevant experience files
- `neon-mythos-experience.js` — PWA/mobile hub, chat, buddy creation, daily mission, demo wallet, highlights.
- `neon-mythos-errand.js` — receive/reply/think/depart/return errand interaction.
- `neon-mythos-route-fx.js` — `! → 💭 → 🏃` head reactions and temporary neon route visualization.
- `scripts/apply-offline-actions.py` — long-term-task persistence + minimal offline catch-up injection.
- `scripts/apply-errand-mode.py` — connects chat errands to real Long-term Tasks and agent movement.
- `scripts/apply-route-fx.py` — injects agent DOM identity and route geometry into the staged build.
