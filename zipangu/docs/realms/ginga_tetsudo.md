# 銀河鉄道・時環線（Galaxy Railway: Time-Loop Line）

> どこまでも行ける切符は、帰ってくるための切符でもある。

この章では、現実の歴史を【史実】、宮沢賢治の作品に書かれていることを【原作】、この世界の作り話を【創作】と記す。

## 分岐点（史実と創作）

【史実】宮沢賢治（1896–1933）は岩手県花巻の人で、童話『銀河鉄道の夜』は晩年まで推敲が重ねられ、定稿のないまま遺された長編として、作者の没後に世に出た。賢治の郷里の花巻には岩手軽便鉄道が走っていて、それが銀河鉄道のもとの一つだとする説がある。また賢治は花巻農学校の教師だったころ、北上川の岸の白っぽい泥岩の岸を「イギリス海岸」と名づけ、くるみの実の化石などを見つけたことを随筆に書いた。プリオシン海岸はこの体験がもとになったといわれる。夜空では、白鳥座が天の川の上に大きな十字を描き（北十字）、その嘴にあたるアルビレオは、望遠鏡で金色と青色の二つの星に分かれて見える。

【原作】少年ジョバンニは星祭（ケンタウル祭）の夜、丘の上の天気輪の柱の下で「銀河ステーション」という声を聞き、気がつくと友だちのカムパネルラと小さな列車に乗っている。ポケットには、四つに折ったはがきほどの緑の切符。白鳥の停車場では二十分停車のあいだにプリオシン海岸へ走り、鳥捕りからお菓子のような雁をもらい、アルビレオの観測所の青宝玉と黄玉の球を見る。

【創作】万華京ジパングでは、作者が世を去り物語が皆のものになったことで「没後の約束」がはたらき、銀河鉄道が青空書庫から降りて、時層をまたぐ環状線「時環線」になった。始発は令和の時片の天の川ターミナルで、十の時片と各異界に駅がある。運行と信号はZEROが、ポイントの切り替えはLIRAの歌が受け持つ。原作の鳥捕りは鳥を捕まえるが、この世界では時層間貿易の掟（生き物の捕獲や移送は禁止）と憲章の「落鱗のみ」の精神に合わせ、砂に残された鳥の形だけを拾う菓子売りに翻案した。そして時環線は南十字へは乗り入れない。原作の旅の終わりの悲しみは原作の頁にそのまま残し、この線は「帰ってくる人のための鉄道」として走る。

## 歩いてみる

明け六つ。あなたは天の川ターミナルのホームで、夜通し走った最終列車を迎えている。ごとごとごとごと、という音が遠くから近づき、黄いろの電燈を一列にともした小さな車両が、白みはじめた空の縁をすべりこんでくる。降りてくるのは、玉手箱を抱えた運び屋、眠そうなエージェント、縄文の駅から乗ってきた土の匂いのする旅人たち。改札鋏がぱちん、ぱちんと鳴るたびに、切符の穴が一つずつ緑に光る。枕木の上では線路番が羽箒を動かして、夜のあいだにアルビレオ揚羽がこぼした落鱗を集めている。やがて朝の光にまぎれてホームは薄くなり、天気輪の柱だけが広場の北の丘に残る。夜の鉄道は、昼のあいだ眠るのだ。

暮れ六つ、逢う刻。全時代の提灯がいっせいに灯ると、丘の上の柱が蛍のように明滅しながら三角標の形に変わる。「銀河ステーション、銀河ステーション」。どこからともなく声がして、目の前がぱっと明るくなったとき、あなたはもう青い天鵞絨の腰掛けに座っている。窓の外には青や橙の燐光の三角標が野原いっぱいに立ち、ガラスよりも水素よりもすきとおった天の川の水が、声もなく流れていく。線路のへりには、月長石で刻んだような紫のりんどうの花。

白鳥の停車場で列車がとまる。大時計の下には「二十分停車」の札。紫がかった電燈がひとつだけの改札口を抜け、水晶細工のような銀杏の広場から河原へ駆けていくと、もう二十分市が立っている。鳥捕りが風呂敷をひろげ、飴色に光る雁を一羽すすめてくる。かじると、遠い笛のような声が耳の奥でかうかうと鳴った。

プリオシン海岸駅では、瀬戸物の標札の下で水晶の砂をすくってみる。粒の中で、小さな火が燃えている。片側の崖には縄文の土器のかけらがのぞき、向かいのホームの屋根には大正の注文雪が積もっている。鷲の停車場の手前で、窓の外の二つの球——青宝玉と黄玉——が重なり、一瞬だけ車室が緑に染まる。丘の上から『星めぐりの歌』が流れ、かちり、とポイントが切り替わった。

## 住むものたち

- **アルビレオ揚羽（あるびれおあげは）**【創作・新種】：夜の藍の翅に、黄玉の金か青宝玉の青の眼状紋をひとつずつもつ揚羽蝶。金と青の二匹がかならず一組で飛び、重なると緑に光る。明け六つ前に枕木の上でこぼす落鱗が、時層パスの検定と翅鱗の最上等級「星鱗」の裏付けになる。
- **甘露雁（かんろがん）**【創作・新種】：天の川をV字の列で渡る、光でできた飴色の雁。砂に降りて飛び立つと、自分の形の光（抜け影）を残し、それが固まってお菓子の雁になる。鳥捕りは雁には手を触れない。
- **訪れるもの**：時片の境を自由に越える虹紫が、ターミナルの屋根の上をかすめていく。白鳥の停車場の燈台は、浅葱硝子斑の渡りの刻にも灯を間引く。

## 働くエージェント

この異界に住みこむエージェントはいない。ZEROやLIRAをはじめ、夜ごと各時片から通ってくる者たちが運賃を払い、荷を積み、線路を守る。

**ZERO**は毎夕、黒曜石の時刻盤を万世時計の十の文字盤と同期させ、鷲の停車場の手前の三角標に信号所を置いて時層ゆらぎを見張る。【長期目標：建設】全時代共通の規格を定め、時環線の全駅を開通させること。新駅の建設資金は、方丈カプセルの軌道移住と銀河鉄道の新駅の胴元を務めるGOLD JACKから出ることも多く、二人は規格と採算のあいだで毎晩のように折り合いをつける。

**LIRA**は浅草の無線座で録った『星めぐりの歌』の音盤を転轍の丘に納め、朔の夜には自分の声で歌ってポイントを切り替える。その報酬の刻を、十の時代の音を一曲に重ねるための制作費に回している（【長期目標：稼ぎ（芸術）】）。

**YAMI-NEKO**はイーハトーヴ駅を兼ねる軽便鉄道の停車場で、夜市へ送る原簿の写しと屋台の部材を貨物枠に積み、ZEROから信号所の裏口を塞ぐ点検を請け負っている（【長期目標：地区支配】）。切符の地紙は、陰陽寮の宇治で星蚕を育てる**ホシイト**が星糸で織って納める（【長期目標：建設】月の都と地上を一本の星糸の航路で結ぶこと）。

昼の空では、烏型飛脚の**DRONE-TAN**が好敵手だ（【長期目標：建設】十の時片すべてに烏港を開くこと）。明け六つと暮れ六つの会所の掲示板で、夜の貨物枠と昼の飛脚便の運賃が並んで貼りだされ、運び屋たちはその差を見て荷を振り分ける。これが「昼と夜の物流差」の裁定取引である。荷はすべて乙姫の玉手箱税関で封じられ、考証印のない品を前の時代の駅で降ろすには重い時差関税がかかる。運賃のもめごとがこじれたときは、イーハトーヴのどんぐり裁判所へ「山ねこ拝」の裁定状を頼みに行く。

## 祭りと事件

- **七夕の臨時増便**（毎年・小暑）：【史実】七夕は旧暦七月七日の夜に星を祭る行事で、いまは新暦や月遅れで行う土地が多い。【創作】時環線は終夜運転になり、切符と貨物枠の値が跳ね上がる。運び屋は半月前から枠を押さえ、烏型飛脚は割引の夕方便で対抗する。
- **ケンタウル祭の烏瓜流し**（毎年・白露のころ）：【原作】星祭の夜、子どもたちは烏瓜の青いあかりを川へ流し、「ケンタウルス、露をふらせ」と叫んで走った。【創作】十の時片の子どもたちが天の川ターミナルの水路から烏瓜のあかりを流す。烏瓜のあかりと火入りの水晶砂が品薄になる。
- **白鳥の二十分市**（毎夜）：【創作】大時計が十一時を指すと二十分だけ立つ市。お菓子の雁、アルビレオ鱗、水晶砂がよく動く。
- **事件：南十字の切符**：【創作】ときどき、南十字行きの切符を求めて窓口に来る旅人がいる。駅員は時環線がそこへは行かないことを告げ、かわりに、帰りの駅まで書きこんだ緑の切符を一枚手渡す。

## この時片の書物

- 宮沢 賢治『銀河鉄道の夜』（作者1933年没）：時環線の原典。天の川ターミナルの窓口の上に掲げられ、新しい乗務員が最初に通読する。原作の結末は原作のまま残し、この世界はその旅を「帰ってくる鉄道」として翻案している。
- 宮沢 賢治「イギリス海岸」（作者1933年没）：プリオシン海岸駅の待合室に置かれた駅の由来書。北上川の岸でくるみの化石を見つけた、ほんものの川岸の記録。
- 転轍の丘で流れる『星めぐりの歌』も、賢治が作った歌である。
