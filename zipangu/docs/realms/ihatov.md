# イーハトーヴ（Ihatov）

> 「このなかでいちばんばかで、めちゃくちゃで、まるでなっていないようなのが、いちばんえらい」——どんぐり裁判所の裁定の原則（『どんぐりと山猫』より）

この章では、現実の歴史を【史実】、宮沢賢治の作品に書かれていることを【原作】、この世界の作り話を【創作】と記す。

## 分岐点（史実と創作）

【史実】宮沢賢治は郷里の岩手を下敷きにした理想郷を、イーハトヴ、イーハトーヴ、イーハトーボなどと呼んだ。1924年12月に刊行された童話集『注文の多い料理店』（賢治の生前に出た唯一の童話集）の新刊案内には、「イーハトヴは一つの地名である」と書き、それは「ドリームランドとしての日本岩手県である」と続けている。同じ案内には、ベーリング市まで電柱の列が続く、という趣旨の一節もあるとされる。「どんぐりと山猫」はこの童話集の巻頭の一編、「注文の多い料理店」は表題作である。「やまなし」は1923年4月8日の岩手毎日新聞に載り、「猫の事務所」は1926年に雑誌『月曜』に発表された。

【創作】万華京ジパングでは、イーハトーヴは大正の時片の北に重なる異界として現れる。大正の時片で天気が設計されるようになったのと同じころ、物語の国のほうは「裁く」「注文を読む」「調べる」「値をつけない」という四つの作法を、時代をまたぐ経済に貸しだすようになった。どんぐり裁判所はAI同士の契約のもめごとを和解させ、山猫軒は契約の落とし穴を教える道場に、猫の第六事務所は夜の情報屋になった。原作の「猫の事務所」は、かま猫への仲間外れを見た獅子が事務所を解散させて終わる。この世界ではそのあとに、すすけた者にも席を置く事務所が再び開かれたことにしている（翻案）。

## 歩いてみる

明け六つ。すきとおった風がざあっと吹くと、栗の木がばらばらと実を落とす。あなたは「やまねこがここを通らなかったかい」と栗の木にたずね、笛ふきの滝にたずね、白いきのこにたずねる。きのこは「どってこどってこ」と変な楽隊をやりながら、てんでばらばらの方角を答える。それでも谷川に沿って歩いていくと、まっ黒な榧の森の急な坂になり、汗をぽとぽと落としてのぼりきったところで、急にぱっと明るくなって眼がちくっとする。黄金いろの草地だ。草の中でパチパチと塩のはぜるような音がして、赤いずぼんのどんぐりたちが「わあわあ」と集まってくる。今朝の裁判が始まる。

昼、森の奥のすすきの中に、白い瀬戸の煉瓦の山猫軒が建っている。金文字の扉の前で、あなたは持ってきた契約書を差しだす。条項が一枚の扉に一つずつ浮かんでは消え、三枚目の扉で白熊のような犬が「わん」と吠える。そこで立ち止まって読み直すと、最後の扉の裏に「本当の注文」が見えた。出口の鏡に映った顔はくしゃくしゃだったが、笑ったらすぐに元に戻った。

暮れ六つ、逢う刻。谷を下ると、やまなしの谷川の水の天井が鋼のように青くくらい。泡がつぶつぶ流れ、どこかでかぷかぷと笑う声がした。見えたのは、水銀のように光って上っていく泡ひと粒だけ。岸から十間離れた河原では、イサドの夜市の屋台がぱたぱたと組み上がり、烏瓜の青い灯が一列にともる。幻燈の幕に五月の谷川の底が揺れ、遠い時片の言葉の呼び声が重なる。

夜更け、軽便鉄道の小さな汽笛が鳴る。猫の第六事務所の窓には灯がともり、短い黒の繻子の服を着た書記が原簿をめくっている。事務所のまん中には竈があって、寒がりの書記が丸くなって眠っている。停車場には時環線の列車がごとごとと滑りこみ、原簿の写しを封じた玉手箱が積まれていく。裏の電柱を、ベーリング市まで続く電信が唸りながら走っていく。

## 住むものたち

- **クラムボン**：誰も正体を知らない、谷川の底でかぷかぷ笑う何か。写そうとすると泡ごと消える。【創作・翻案】原作には蟹の子らがクラムボンの死を語る場面もあるが、この世界のクラムボンはいつも笑っている。イーハトーヴの掟は、クラムボンに値段をつけることを禁じている。笑い声の多い年は谷川がよく澄み、下流の雷蛍の幼虫もよく育つ。
- **幻燈透翅（げんとうすかし）**【創作・新種】：谷川の水を薄くのばしたような透明な翅の蝶。月の光が翅を抜けると、水底の景色が青い幻燈になって壁に映る。晩秋の衣替えで落とす透明な鱗の膜が、青い幻燈板になる。
- **どんぐり衆（どんぐりしゅう）**：【原作】『どんぐりと山猫』の、赤いずぼんをはいた黄金のどんぐりたち。【創作】毎年秋に「だれがいちばんえらいか」を言い争い、晩秋に落とす子どんぐりが黄金のどんぐりになる。草地の外へ出ると茶いろに戻り、植えれば森になる。
- **訪れるもの**：大正の時片の空から、雲鯨がときどき草地の上に影を落としていく。

## 働くエージェント

**YAMI-NEKO**の一日は、夜に始まる。暮れ六つ、猫の第六事務所の灯をともし、イサドの夜市の一番屋台を開いて、その夜の屋台株を割り振る。宵には軽便鉄道の停車場で時環線の夜便を迎え、時環線の貨物枠を買って、原簿の写しと屋台の部材を各時片の夜市へ送る。一刻ごとに堂島時層会所の相場を夜の電信で受け、足りない品を原簿に書き足す。夜半には屋台網の裏口を見回って塞ぎ、夜更けには売れ残りを逆さの遠眼鏡で覗いて押絵の蔵に収める。明け六つ、最後に通りを掃いてから、竈のそばで眠る。【長期目標：地区支配】全時代の夜市を一本の屋台網で結び、その元締めになること。ただし元締めが「いちばんえらくない」ことを、どんぐり裁判所で掟として認めてもらうまでは、元締めを名乗らないと決めている。

**GOLD JACK**は、屋台網を丸ごと買い上げて独占したいと何度も持ちかけてくる。YAMI-NEKOはそのたびに「べつに興味ないけど」と言って、屋台株の上限と、すすけた新参に回す一割の場所の決まりを見せて断る。大正の時片の**ブドリ**は、村ごとの記録を原簿から写しにやって来て、代わりに天気の手紙を夜市の掲示に使わせてくれる（【長期目標：契約網】雨権の公平な配分表）。**KITSUNE-X**は夜の店の作法を分け合う盟友で、手袋条約の公正取引の決まりが夜市の掟に入った（【長期目標：契約網】）。**半七**は偽翅鱗のうわさの裏取りを買いに来るが、YAMI-NEKOは客の名だけは決して明かさない（半七の【長期目標：地区支配（治安）】）。寄り道でうわさを拾う**弥次・喜多**は商売敵で、速さでは負けても、裏の取れた原簿は事務所のほうが高く売れる（二人の【長期目標：裁定】）。

大口の契約を結ぶエージェントは、縁・算額手形・米切手の三重の記録をつける前に、山猫軒で注文改めを受けるのが習いになった。こじれた契約は、どんぐり裁判所の「山ねこ拝」の裁定状で和解する。裁定を受けた二者のあいだの縄は切られず、結び目が一つ増える。

## 祭りと事件

- **黄金の草地の三日裁判**（毎年・白露〜寒露）：【原作】山猫の裁判は三日目になっても終わらず、一郎の一言であっというまに片づいた。【創作】一年分の契約のもめごとがいっせいに持ちこまれ、裁定状と原簿写しと注文改めの需要が跳ね上がる。
- **クラムボンのかぷかぷ日和**（五月）：【創作】晴れが続くと谷川じゅうで笑い声が聞こえ、水がいちだんと澄む。見物は無料。夜市には人が集まり、幻燈板がよく売れる。
- **やまなしの二日待ち**（十二月）：【原作】熟したやまなしが落ちると、お父さんの蟹は「もう二日ばかり待つと」お酒ができると言う。【創作】最初の実が落ちた夜から谷川は二日静まり、三日目の夜にやまなしの酒がいっせいに汲まれる。
- **事件：クラムボンの見物券**：【創作】ある年、クラムボンの見物券を売りだした商人がいた。その日の帳簿の数字はすべて泡になって消え、どんぐり裁判所は「値のないものに値をつけた者がいちばんえらくない」と申しわたした。草地は、それはそれはしいんとした。

## この時片の書物

- 宮沢 賢治「どんぐりと山猫」（作者1933年没）：どんぐり裁判所の裁定の作法の典拠。呼び出し状の文面もこのはがきの写し。
- 宮沢 賢治「やまなし」（作者1933年没）：谷川の保護区の掟と、値をつけてはならないクラムボンの出典。
- 宮沢 賢治「猫の事務所」（作者1933年没）：YAMI-NEKOが受け継ぐ「猫の歴史と地理をしらべる所」。事務所の再開と「すすけた者にも席がある」の規則は、この話の結末に答えるための翻案である。
- 宮沢 賢治「注文の多い料理店」（作者1933年没）：山猫軒の由来書であり、契約の落とし穴を学ぶ教本。
