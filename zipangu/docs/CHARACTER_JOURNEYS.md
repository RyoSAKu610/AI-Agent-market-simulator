# 住人との会話・お願い・旅の記録

32人の設定は `world/agents.json` のまま。`character-profiles.js` はこのゲームで使う追加の創作台詞と小さな次の望みを定義します。史実の人物の発言・行動として扱いません。外部AI・APIキーは使わず、自由入力から扱える話題を判定する規則応答です。不明な言葉は候補を示して聞き返します。

## 実際にできるお願い

- **現地記録**：本人の本拠へ実際に移動し、その場所・刻・節気を記録。職人・相場師は原設定のひいきの品の現地価格、時計・観測役は現在の刻を記録。森や庭の案内は正本の場所の説明を使い、生き物を実際に目撃したとの断定はしません。
- **本拠への案内**：本人が本拠へ移動して案内を残します。訪問者自身の位置や移動は未実装です。
- **封じた伝言**：運び・交渉を担う住人に限り、正本で縁のある相手の本拠へ120文字以内の伝言を運びます。投函時と、相手が帰宅して読む時は別の実イベントです。相手も現在の仕事を終えてから帰宅します。伝言はこの架空世界の中だけで、外部への送信はありません。

今の経済計画と荷物を中断せず、そのあと既存の react → think → travel → trade を使って実行します。銀河鉄道の夜待ち、運賃と財布、位置、ルートは既存シミュレーションと共通です。一人につき実行中1件、待ち1件。受領だけで完了にせず、現地到着と作業時間の経過が必要です。ザシキは約束しない設定を守り、依頼を断ります。捕獲・羽衣・福の売買・贈り主の売却などは拒否します。物資を作り足したり、新しいお金の報酬を付与したりしません。

## 成長と記憶

「出会いの頁」「初めて結んだ約束」「記録を重ねる道」「願いへの小さな一歩」は、果たした約束、現地記録、実際の細工、既存経済目標の節目から派生します。会話だけで信頼・経験は増えません。同じゲーム日・種類・行き先の反復は信頼を重ねず、イベント連番により復帰後の二重反映も防ぎます。

現在の依頼・疲れ・実記憶から気持ちを変え、32人それぞれの次の望みへつなげます。森の拡大や百年百合の開花、駅の完成そのものを計算したとは扱いません。実際の初訪問、細工、商い、目標の節目が旅の記録に残ります。伝言の本人受取は両者の通信の記録に反映され、正本の関係は書き換えません。

一人の保持上限：会話24件（各900文字）、旅の記録40件、思い出8件、依頼16件。古い記録は順に整理されます。記録の範囲は画面でも明示します。

## 同じ旅を再開する

`zipangu.journey.v1:<seed>` に経済snapshot・依頼・記憶・成長・相場の実観測履歴を一つのJSONとして保存します。5秒ごと、会話/お願い後、非表示化/終了時に保存。復帰時は150秒の初期warmupを行わず、閉じていた時間も進めません。乱数・時計・位置・持ち物・未完の移動や作業・イベント連番が続きます。

価格履歴は直近72観測の共通時刻と、Float64をそのままbase64にした配列。価格を丸めたり観測を補ったりせず、既存チャートの点数・値・時刻を復帰します。32人に会話を持たせ、実際の経済を進めた72点の検証例はUTF-16換算 **2,267,548 bytes**。容量不足・保存不可は画面に表示します。別端末・別ブラウザ・別originには共有されません。

不正/読めない記録は上書きせず一時的な世界を開きます。画面で明示した「元の記録を消して新しい旅を保存」を押した時だけ保存を再開します。ブラウザのサイトデータ消去でも記録は消えます。

会話の入力欄と送信フォームは定期更新で再生成しません。日本語IME変換中の送信を避け、入力内容・フォーカスを保持します。絵の停止と reduced-motion は既存の原画表示の仕組みを継承し、経済は継続します。

## 検証

`tools/character-stories.test.mjs` は全32プロフィール、会話のみで成長しないこと、依頼拒否・順番待ち・実移動・成功・snapshot継続・伝言投函と帰宅後受取・イベント重複・保存異常・価格履歴復帰を検証します。既存root/zipanguチェックとsingle HTMLも検証対象です。

ローカルMacの上位CommonJS環境とTMPDIR干渉は、既存と同じ `/private/tmp` への一時コピーでzipanguチェックを実行し、assetsを元ディレクトリへsymlinkします。リポジトリにpackage.jsonは追加しません。

実ブラウザ（Chromium）では1280×800と390×844のtouchで、ZERO/カミフダ/ザシキの会話と依頼、入力・フォーカス保持、実移動中の復帰、成功後の成長章、全32入口を確認。PCの相場履歴は再読み込み前後の点数・価格・時刻を完全一致で確認しました。カミフダの伝言は第2日投函→第3日のORACLE帰宅時に受取、両者の通信記録が1回増えることを確認。壊れたJSONの非上書きとlocalStorage利用不可も実機確認。各確認でJSエラー0、横はみ出し0でした。

単独HTMLはHTTPで全体を読み込んだあと、ブラウザをofflineに切り替えて会話・保存・原画・相場を確認。HTTPでの再読み込みでは同じ依頼ID・信頼・時計・実履歴が復帰しました。代表起動2.3秒、アルビレオ揚羽の対は原寸1254pxのBlob画像として表示、通信失敗/JSエラー0。直接file URLでの起動は今回の確認方式ではありません。生成物は約409MBで従来同様gitには含めません。
