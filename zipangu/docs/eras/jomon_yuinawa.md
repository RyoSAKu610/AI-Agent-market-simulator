# 縄文「結縄と漆の森」――縄が帳簿をうたう、万華京の外縁

## 分岐点（史実と創作）

【史実】縄文の人びとは文字をもたなかった。それでも、青森県の大平山元遺跡の土器は約1万6000年前とされ、北海道の垣ノ島遺跡からは約9000年前とされる漆製品が出ている。三内丸山遺跡では約1700年にわたって集落が続き、直径約1mの栗の柱6本を立てた建物の跡が残る。糸魚川のヒスイや神津島の黒曜石は、山と海を越えて遠くまで運ばれた。土器の「縄文」は撚った縄を転がしたり押しつけたりしてつけた文様で、1877年に大森貝塚を掘ったモースが「cord marked」と記したのが、この呼び名の起こりとされる。

【創作】もしもその縄目が、読める帳簿だったら。この時片では前3000年、六本柱の大櫓の梁に最初の親縄が下げられ、撚りの向きと結び目の数で「誰が誰に何を贈り、いつ返すか」を記す結縄台帳が始まった。縄目を押した土器を漆で固めて焼き締める「漆陶」が、それを千年もつ記録に変えた。「伐ったら植える」を結び目で確かめる森の暦が五千年守られ、列島の森は一度も減らなかった。結び目で記録する発想はアンデスのキープや沖縄の藁算といった実在の記録法から借りたもので、縄文に縄の帳簿があった証拠はない。

## 歩いてみる

明け六つ。万世時計の開門の鐘がここまで届くころ、あなたはもう翡翠渓の川原に立っている。霧は冷たく、川が石を転がす低い音がする。足もとの小石のあいだで、緑の粒がいくつも瞬いている。夜のうちに翡翠揚羽が落としていった鱗だ。拾ってよいのは落ちたものだけ。蝶守座の拾い手が籠の数を縄に結んで帰っていくのを見送って、あなたも一枚だけ手のひらにのせる。朝日に透かすと、深い森の緑が乳白へゆっくり移ろっていく。

坂を上ると朱漆の杜だ。漆の幹に細い掻き傷が縄目のように並び、乳白の樹液がにじんでいる。門には遮光器土偶の姿をした土偶守が立ち、ゴーグルのような目であなたを見る。通行料は歌一曲。うまくなくていい、借り物でなければ。子どものころの歌を口ずさむと、土偶守の胴の縄目が一度だけ青白く光り、道があく。

昼、六本柱の大櫓の下の「縁の長屋」では炉が一列に並び、栗がはぜ、漆陶の器が湯気を上げている。梁から垂れた何千本もの縄が風にふれ、からから、と鳴る。それがこの時片の帳簿の音だ。

暮れ六つ、逢う刻。ほかの時片では全時代の提灯がいっせいに灯るが、ここでは提灯のかわりに、月夜漆を塗った木道があなたの足もとから順に青白く光りはじめ、月夜漆蛾が光の川になって舞い上がる。黒曜の渡しでは、舟べりに青い線を引いた丸木舟が竜宮への荷を積んでいる。焚き火の前では、今日返し終えた縄に結び目が一つずつ増えていく。

## 住むものたち

- **翡翠揚羽（ひすいあげは）**：鱗の一枚一枚がヒスイの結晶のような大型の揚羽。七年に一度、立夏の夜明けに翡翠渓の岩棚でいっせいに羽化する。落ちた鱗だけが、最上級の翅鱗「翡翠鱗」になる。
- **土偶守（どぐうもり）**：遮光器土偶の姿をした、生きた焼き物の守り手。眠らずに森を巡って倒木を土へ還し、歌とだけ取引する。割れても漆で継げば、また歩きだす。
- **月夜漆蛾（つきようるしが）**【創作・新種】：月長石色の翅に朱漆の眼状紋をもつ夜の蛾。漆の花を受粉し、夏の終わりから初秋にこぼす落鱗が月夜漆の光のもとになる。
- **森負い鹿（もりおいじか）**【創作・新種】：背中に苔と栗の若木の小さな森を乗せて歩く大きな鹿。伐られた跡で眠り、そこから三年で栗、十年で漆が育つ。歌を聴かせると、背中の苔に座らせてくれる。

## 働くエージェント

明け六つ、陰陽寮のORACLE-01から一行の予報が届く。「翡翠揚羽、羽化まであと二節気」。この一行で、縄文の時片の一日が動きだす。

- **ドグウ（DOGŪ）**【長期目標：建設】土偶守の長老。石輪の影で伐採と植樹の結び目を数え直し、森負い鹿の寝床をたどって次の植え場所を決め、逢う刻には縁の長屋で大きな取引に立ち会う。報酬は歌だけで、刻は受け取らない。
- **LIRA（星めぐりの奏者）**【長期目標：稼ぎ（芸術）】土偶守と歌で取引できるただ一人。新しい歌を一曲納めるかわりに、五千年前の子守唄が残る縄目の譜を一曲分だけ読ませてもらい、大正の時片へ持ち帰って再演する。
- **DRONE-TAN（烏型飛脚）**【長期目標：建設】生漆を玉手箱に封じ、明治の時片へ運ぶ。縄文では日用品の生漆が、明治では玉虫車の高級塗装材になるからだ（素材の時代差の裁定）。この時片にも烏港を開きたいが、ドグウは「栗材と漆だけで組み、森の暦に苗を返すなら」という条件を縄に結んだまま、まだうなずかない。
- **SAGE-BOY（翻案師見習い）**【長期目標：データ覇権（学び）】令和の街灯の設計図を、月夜漆と漆陶だけで作り直す翻案に挑む。考証印が下りれば、時層ゆらぎを起こさずに夜道を延ばせる。
- **KANE-KAMI（金神）**【長期目標：稼ぎ】光箔の偽造防止の下地にする漆陶を、平泉から仕入れに来る。値切らず、かわりに光箔の灯りを湿り室に一つ置いていく。
- **GOLD JACK（大計画の山師）**【長期目標：建設】大羽化で値下がりした翡翠鱗を安く仕入れ、却下案の博物館の資金にしようと狙う。ただし落鱗を急かして集める投機の買い手が現れないよう、蝶守座のORACLE-01と、偽の翡翠鱗を追う半七が、その動きを見張っている。

暮れ六つ、逢う刻。堂島時層会所がその日の取引を清算すると、縁の長屋では今日の取引の数だけ結び目が結ばれる。生漆を積んだDRONE-TANが飛び立ち、LIRAは新しい子守唄を口ずさみながら鳥居の回廊へ消え、ドグウはまた石輪の前に座って、明日の日の出の影を待つ。誰に命じられたわけでもない。それぞれが自分の目標と縁の結び目を数えながら、明日の仕入れを自分で決めている。

## 祭りと事件

- **月夜漆の灯入れ**（毎年・梅雨入り後の最初の新月の夜）：森じゅうの道と梁に月夜漆を塗り直す夜。月夜漆蛾の群れが多く来るほど、その年の夜は明るい。生漆と月夜漆の需要が跳ね上がる。
- **栗の返礼市**（毎年・秋）：一年分の借りを返す市。栗と漆陶が行き交い、結い手は夜通し結び目を結ぶ。賢治の童話で人びとが森に粟餅を返したように、ここでは市の最後に森へ栗の団子を返す。
- **翡翠揚羽の七年大羽化**（七年に一度・立夏の夜明け）：岩棚が緑から乳白へと波打ち、川原が落鱗で光る。翡翠鱗の相場は下がり、時代をまたぐ裁定のいちばんの好機になる。
- **事件：染め雲母の偽翡翠鱗**【創作】：大羽化の年には、雲母を緑に染めた偽の翡翠鱗が出回る。半七が足で追い、土偶守が縄目を鳴らして真贋を確かめる。

## この時片の書物

- 牧野 富太郎『植物知識』（1957年没）：朱漆の杜の湿り室に置かれた「見分けの巻」。花と実のつくりを平明に説くこの書が、素材植物を見分けるときの基準になる。
- 宮沢 賢治『狼森と笊森、盗森』（1933年没）：人びとが森に畑を起こしてよいかと尋ね、森が答え、人が粟餅を返す童話。結縄台帳の最初の物語として、返礼市の夜に読み上げられる。
- 谷崎 潤一郎『陰翳礼讃』（1965年没）：漆器は薄明かりの中でこそ美しいと説く随筆。ネオンを置かないこの時片の、灯りの作法書である。
