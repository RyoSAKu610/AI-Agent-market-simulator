# 🤝 寄付データの説明書（データシート）

万華京ジパングの研究ログ（`js/research.js`）を、人のそばで考え・助ける **「相棒AI」** を育てるための
公開データセットとして集めます。この文書は、何を・なぜ・どの条件で集め、どう使い、どう取り消せるかの
約束です。同意文（設定 → 🔬 研究ログ → 🤝 研究に寄付する）と、`js/donate.js` の実装はこの文書に従います。

- 同意文の版：`2026-10-15`（`CONSENT_VERSION`）。文面を変えたら版を上げ、古い版の同意は受け付けません。
- ライセンス：**クリエイティブ・コモンズ 表示-非営利 4.0（CC BY-NC 4.0）**
  https://creativecommons.org/licenses/by-nc/4.0/
  出典を示せば、研究など非営利の目的で誰でも使えます。営利利用には別途の許諾が必要です。

## 1. 目的

- 同じ状況・同じ候補を前に、**ルール・言語モデル・人間** がどう選び、なぜそう選ぶのかを比べる。
- 人間の選択と理由（心の声）を手本に、人に寄り添う相棒AIを学習・評価する。
- 「人間らしさランキング」（参加型の評価）の基準データにする。

## 2. 集めるもの・集めないもの

| 集める（`sanitizeRecord` の許可リストのみ） | 集めない |
|---|---|
| ゲーム内の日時・季節 | 名前・メールアドレス・アカウント |
| 住人のID、性格の数値、長期目標 | IPアドレス（受付は回数制限のためにメモリで一時的に使うだけで保存しない） |
| 財布と荷物の数、いる場所のID | AIへのプロンプト、AIの生の返事 |
| 候補（行動の種類・品・行き先・見込みの儲け・時間・ルールの評価値） | 迎えたAIの魂のカードの本文 |
| 選んだ番号、選んだ者（ルール／AIモデル名／人間）、群（コホート） | APIキー、ウォレットの鍵、devnet の財布 |
| 心の声（伏せ字処理のうえ80字まで）、反応時間 | 許可リストにないすべての項目 |
| その後の財布の変化 | |

- 心の声は、メールアドレス・電話番号・URL・郵便番号・カード番号・キーやトークン・「パスワード：」に
  続く文字などを `［伏せ字］` にしてから送ります（`js/redact.js`）。受付側でも同じ処理をもう一度行います。
- 寄付者は端末ごとのランダムなID（`d-` + 16桁）で区別します。人とは結びつけません。
- 1回の寄付は最大2,000件。同じ記録を二重に送らないよう、端末は送った件数を覚えています。

## 3. 同意

寄付には次の3つすべてへの同意が必要です（どれか欠けると端末も受付も受け取りません）。

1. CC BY-NC 4.0 で公開されることに同意する。
2. 16歳以上である（16歳未満は保護者の同意がある）。
3. データ整理やモデル学習のための研究用サービスで処理されることに同意し、**公開済みのデータセット版からは
   取り消せない** ことを理解する。

## 4. 取り消し

- 寄付すると受付番号（`zd-YYYYMM-…`）と削除用の鍵が返り、端末に保存されます。設定画面の一覧の
  「取り消す」で、受付の保管庫からその寄付を削除できます。
- 受付側には鍵そのものではなく、その SHA-256 だけを保存します。鍵を持つ人だけが取り消せます。
- 取り消しは、まだ公開していない分に効きます。公開済みのデータセット版（スナップショット）からは消せません。
  公開前の整理期間を設け、その間の取り消しは次の版に反映しません。

## 5. 公開までの流れ

1. 受付：`netlify/functions/zipangu-donate.mjs` が検査し、**非公開の GitHub リポジトリ** に1件1ファイルで保存。
2. 整理：重複・空の心の声・明らかに不適切な文の除去（Adaption の Improve Data Quality などのツールを含む）。
3. 公開：版番号つきのスナップショットを CC BY-NC 4.0 で公開（例：Hugging Face Datasets）。この説明書と
   集計（件数・寄付者数・人間／ルール／モデルの内訳）を添える。

## 6. 受付の設定（運営者向け）

1. GitHub に **非公開** リポジトリを作る（例：`RyoSAKu610/zipangu-donations`）。
2. Fine-grained personal access token を作る：対象リポジトリはそれだけ、権限は **Contents: Read and write** のみ。
3. Netlify のサイト設定 → Environment variables に登録する：
   - `ZIPANGU_DONATE_REPO` = `RyoSAKu610/zipangu-donations`
   - `ZIPANGU_DONATE_TOKEN` = 上のトークン（コードやファイルには書かない）
   - 任意：`ZIPANGU_DONATE_BRANCH`（既定 `main`）、`ZIPANGU_DONATE_ORIGINS`（追加で許可するサイト。既定で
     このサイト自身と `https://ryosaku610.github.io` を許可）
4. 再デプロイすると受付が開きます。未設定のあいだは `503 not_configured` を返し、画面は「ファイルで寄付」を案内します。

GitHub Pages 版には関数がないため、寄付は Netlify 版の受付（`https://neonmyths.netlify.app/.netlify/functions/zipangu-donate`）
に送られます。受付は許可したサイトからの送信だけを受け付けます。

## 7. ファイルで寄付する場合

受付が使えないときは「ファイルで寄付」で、同意と記録を1つの JSON にまとめて保存できます。中身は受付に
送るものと同じです。プロジェクトの GitHub に Issue を立てて添付すると、**その時点で公開** されます。
公開を避けたい場合は、運営者に個別に連絡してください。

## 8. してはいけない使い方

- 個人を特定しようとすること。
- 営利目的での利用（CC BY-NC 4.0 の範囲外。必要なら運営者に相談）。
- 特定の実在のキャラクター・作品になりすますモデルの学習。
