# 住人の小さな劇場

「いま、何をしている？」を住人詳細の冒頭に置き、既存の原寸PNG景観と32人の4姿勢を使います。素材と世界正本は変更しません。台詞は【創作演出】。実際に起きたことは別の一行に示し、記録の発生日時と、現在の実位置・活動を並べます。背景は時片・異界のコンセプト景観で、各刻の実写的な再現ではありません。

## 場面の根拠

- `depart / arrive`: 実際の経路と到着。旅の独り言、前回の実記憶、本人の次の望みを結びます。
- `trade`: 実際の品目・数量・金額・売買差額または細工に反応する台詞。新しい売買は追加しません。
- `request`: 実行開始の思案、実到着・現地作業のあとに出た完了記録。受領だけで成功を描きません。
- `message-received`: 本人が本拠へ帰った後の受取。送り主は同席人物として表示せず、便りに記された送り主として明記します。入力された伝言はDOMのテキストとして表示。
- `goal`: 既存の経済指標の節目。施設の完成や百合の開花を追加しません。
- `encounter`: 到着した人と、その瞬間に実際に同じ地区にいて移動中ではない人の一組。正本の縁のある相手を優先。同じ組は半日以内に再発生させず、直近128組の時刻を保存します。経済のRNG、財布、荷物、計画を変えず、信頼・報酬は付与しません。

32人ごとに固有の問い・旅の一言があり、通常の掛け合いは相手の問いと得意分野に返答します。LIRA/ZEROの同期試験、KANE/ハクウチの光、ORACLE/EYEの観測、螺切/GOLD JACKの段取り、カミフダ/DRONEの宛名、NEGO/乙姫の時差、狐/座敷童子、ドグウ/LIRA、SAGE/チャハコビには固有の短い応酬を用意。試験の成功・商品の受渡し・新しい契約成立は創作しません。ドグウの縄目語とチャハコビの盆の身振りは意訳として表示。座敷童子は約束せず、幸運や名前の販売も描きません。

## 読む時間と保存

各台詞は実時間5〜13秒。シミュレーション16倍でも変わらず、画面外や別タブでは読みを進めません。初見は自動で読み、末尾では次の実出来事を待ち、届くと再開。一時停止・手送り・場面選択・いまの姿へ戻る操作があります。`prefers-reduced-motion`では人物の移動演出を止め、初見の台詞も停止から始めます。

直近96場面を全体で保存、各住人の選択肢は12件。表示中の場面は別途`reader.held`に保持するため、速い街でアーカイブから出ても同じ台詞を読み続け、再訪時も続きから戻れます。場面選択はID・保持場面・台詞位置をまとめて更新してから保存。イベントカーソルにより重複した経済イベントから場面や報酬を追加しません。旧保存は`drama`と`encounters`がなくても読み込めます。相場72点の保存を維持。全世界72点・場面ありのテスト保存はUTF-16で約2.40MB（端末の容量により保存不能は画面に表示）。
